# RWLab 只读网页预览

网页地址：<https://miloyouyou.github.io/rwlab2022-preview/>

本公开仓库只存放用于 GitHub Pages 的静态 HTML、样式、脚本、图片和公开附件。它不能运行 ASP.NET 后台，也不含 C# / Razor 源码、SQL 数据库、账号、私有论文或服务器配置。

访客可以浏览网页，也能像浏览任何公开网站一样查看或保存前端文件；“只读”指访客不能直接修改本仓库或网站内容，并不意味着 HTML、CSS、JavaScript 可以保密。完整网站源码位于所有者的独立私有仓库，只有获得仓库授权的账号才能访问。

这是审阅快照，不是正式官网。历史会议网站以公开档案形式提供，原有在线报名、投稿、支付及后台操作不开放。网站更新必须先在私有工程验收，再由所有者分别同步私有源码与本静态预览。
