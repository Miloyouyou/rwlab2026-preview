2021年国际智能化焊接制造研讨会(IWIWM'2021)

更新时间：2022.01.07 历史资料

       由中国焊接学会机器人与自动化专业委员会等学会机构主办，上海交通大学和新加坡南洋理工大学承办的2021年国际智能化焊接制造研讨会(IWIWM'2021)于2020年12月28-30日在上海交通大学和兰州理工大学、华南理工大学、江苏科技大学、北京石油化工学院线上、线下如期举行。

       会议开幕式由中国焊接学会机器人与自动化专业委员会主任、教育部长江学者、上海交通大材料学院陈善本教授主持，线上出席本次会议的国内外代表300余人, 线下上述5个分会场参会人员约在100余人。其中包括：

       中国焊接自动化领域的奠基人、中国科学院院士、南昌大学荣誉校长、清华大学潘际銮教授；中国工程院院士、哈尔滨焊接研究所技术委员会主任、中国机械科学研究总院首席技术专家林尚扬教授；国际焊接学会(IIW)前副主席、中国焊接学会前理事长、中国机器人焊接技术领域奠基人之一、哈尔滨工业大学吴林教授；中国焊接学会副理事长兼秘书长何实研究员；上海交通大学材料科学与工程学院副院长李铸国教授等专家出席了线上、线下会议并致辞。

       美国橡树岭国家实验室冯智力研究员、南洋理工大学周伟教授、美国得克萨斯州立大学陈和平教授、澳大利亚斯威本科技大学陈小奇教授、美国肯塔基大学的张裕明教授，以及卧龙岗大学潘增喜教授等知名学者在线上参加了会议。

参与本次会议的企业代表有：伏能士智能设备(上海)有限公司WBA高级经理陈贇先生、北京博清科技有限公司市场总监时光先生、广州瑞松智能科技股份有限公司智能技术研究院院长唐国宝先生、中国船舶集团有限公司第七二五研究所吴艳明博士以及江苏北人智能制造科技股份有限公司陈兴先生。

       此外，中国焊接学会机器人与自动化专业委员会的北京石油化工学院焦向东教授，北京建筑大学汪苏教授，天津大学罗震教授，哈尔滨工业大学的张广军教授、兰州理工大学樊丁教授、华南理工大学薛家祥教授和石永华教授、北京石油化工学院薛龙教授、江苏科技大学芦笙教授、李瑞峰教授和黎文航教授，以及上海交通大学华学明教授、张华军研究员、陈华斌副教授、李芳副教授和许燕玲博士等代表线上、线下出席会议。

       本次会议特邀专家作了精彩的大会特邀报告和主题报告，其中包括：德克萨斯州立大学与肯塔基大学陈和平教授、张裕明教授的“智能焊接制造中的机器学习”（Machine Learning in Intelligent Welding Manufacturing）；澳大利亚卧龙岗大学潘增喜教授的“基于机器学习的WAAM 过程缺陷检测”（ Defect detection of WAAM process using machine learning）；新加坡制造技术研究院与南洋理工大学的毕贵军、周伟教授的“用于智能激光增材制造的数字化、传感化和机器学习”（ Digitization, sensorization and machine learning for intelligent laser additive manufacturing）；浙江大学王柏村教授的“走向以人为本的智能制造”（ Toward Human-centric Intelligent Manufacturing (HIM)）；兰州理工大学樊丁教授的“电弧增材制造中的新型制造方法和工艺分析”（Novel fabricate methods and process analysis in the arc additive manufacturing）。会议特邀报告（Invited speech）设两个分会场，共有15篇报告；本次会议还在上海、广州、兰州、北京、镇江五地共设了5个分会场，经推荐选择（Selected paper）的口头报告共计64篇。

       会议最后，来自国内外各大高校的知名学者、企业专家围绕国际机器人焊接、智能化与自动化等主题展开中英文会场分组报告，与会企业报告其技术产品及其研发进展，并与到会专家学者探讨科研与生产实际中遇到的难点疑点问题，为日后学者间的交流建立了良好的沟通桥梁。

       本次会议得到了国内外机器人焊接、智能化和自动化领域诸多专家、学者和同仁们的全力支持，为期三天的学术会议，内容丰富、涉及面广，从研究方向来说涵盖了机器人智能焊接技术、深度学习、数字孪生技术、质量在线监测、电弧物理特性及控制、腐蚀机理与防护、焊接学科文献计量学研究，从制造工艺来说包括了电弧焊、等离子焊、激光焊、激光-电弧复合焊、大型构件窄间隙焊、机器人搅拌摩擦焊、金属表面沉积修复、3D打印，所研究的材料包括铝合金、不锈钢、超高强钢、镍基高温合金、高熵合金。不仅为焊接制造、自动化以及人工智能等多学科交叉领域的交流提供了论坛，也为企业展示成果和引进技术提供了平台。

       本次会议得到了国内外与会专家和代表的高度赞誉，称赞本届IWIWM’  2021会议办出了IWIWM系列会议学术新高度、新水平，被参会代表称赞之为本领域最高水准的“学术盛宴”。

       12月30日，2021年国际智能化焊接制造研讨会议圆满闭幕。

     （供稿：机器人焊接智能化技术实验室 李旭 陈华斌）2021年12月30日
